这是一份速查手册，涵盖本站（Quartz）的全部常用功能。每个功能配有**源码**和**渲染效果**，可以直接复制修改。

## 文件操作

### 创建新笔记

在 `content/` 目录下新建 `.md` 文件即可。文件名会成为 URL 的一部分。

```
content/
  notes/
    电路设计/
      如何选型MOS管.md        ← 新建的笔记
```

### 文件夹即分类

Quartz 会把文件夹结构自动变成侧边栏导航和面包屑路径。

```
content/notes/电路设计/如何选型MOS管.md
     ↓ 自动生成
网站首页 > notes > 电路设计 > 如何选型MOS管
```

## 双向链接

用 `[[ ]]` 链接到其他笔记。Quartz 自动生成**反向链接**（右侧栏显示哪些页面链接到了当前页面）。

```markdown
[[notes/电路设计/如何选型MOS管]]
[[notes/电路设计/如何选型MOS管|点我查看]]
```

**渲染效果**：

[[notes/网站搭建/个人网站搭建全记录]]&nbsp;&nbsp;← 无自定义文字

[[notes/网站搭建/个人网站搭建全记录|点我查看]]&nbsp;&nbsp;← 自定义了显示文字

## 标签

在 Frontmatter 中定义标签，Quartz 会自动生成标签页面。

```yaml
---
tags:
  - 电路
  - MOSFET
  - 功率器件
---
```

**渲染效果**：顶部和底部自动出现标签徽章，每个标签可点击，跳转到 `/tags/电路` 等页面。

（本页面顶部的「教程」「网站」标签就是例子。）

```verilog
module counter(
    input clk,
    input rst,
    output reg [7:0] count
);
    always @(posedge clk or posedge rst) begin
        if (rst) count <= 8'd0;
        else count <= count + 8'd1;
    end
endmodule
```


Quartz 内置语法高亮，支持 C、Python、Verilog、Bash 等几乎所有常见语言。

## 构建与预览

改完内容后重新构建：

```bash
cd 项目目录
npx quartz build --serve --port 8080
```

浏览器打开 `http://localhost:8080`。

如果提示端口被占用：

```bash
taskkill //PID <进程ID> //F
npx quartz build --serve --port 8080
```

构建后的静态文件在 `public/` 目录。部署时只需要把 `public/` 的内容上传到托管服务器。

## 网站结构速查

```
项目目录\
  content/                  ← 📝 你只关心这个目录
    index.md                ←   首页
    archive.md              ←   归档
    categories.md           ←   分类
    friends.md              ←   友链
    about.md                ←   关于
    assets/                 ←   图片等静态资源
    notes/                  ←   笔记（按主题建子目录）
      网站搭建/
      计算机/
      电路设计/
      嵌入式/
      机械设计/
      文史哲/
      音乐美术/
      生活/
  quartz/                   ← 🔧 框架源码（不要改）
  quartz.config.ts          ← ⚙️ 站点设置（极少改动）
  quartz.layout.ts          ← 🎨 页面布局（极少改动）
  public/                   ← 🏗️ 构建输出（自动生成，勿手动改）
```
